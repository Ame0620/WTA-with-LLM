# MANIFEST — DN-WTA v4 数据集（v3 规模扩展族，固定划分协议）

> 生成日期：2026-09-08 ｜ 生成器：`experiments/gen_dn_data.py`（md5 `1bda6548a7712327aa9b24c54f5af14f`，放开每波数量限制 `n/K == 5` 后的版本）
> 文件格式：DN-WTA v1（8 字段 Header + 三块，1+n+2mn 行）；动力学/信息边界/指标口径与 v3 完全一致，见 `DN-WTA_v4_数据集说明.md`。
> 定位：**规模扩展基准（m=5、n=100）**，用于验证算法在更大问题规模与更多 Agent 下的可扩展性；v3 仍为正式主基准。v4 实例与 v3 无继承关系（参数不同、生成流不同）。

## 1. 固定划分（与 v3 协议完全平移，禁止混用）

| split | 实例 | 用途 |
|---|---|---|
| **test** | s01–s02（2 个） | **v4 规模对比基准**：算法在 v4 上的对比统一只用这 2 个实例（× 30 MC seeds） |
| train | s03–s26（24 个） | MARL 训练 |
| val | s27–s30（4 个） | 调参 / 早停 |

任何算法的超参**不得**依据 test 表现调整。基线（none/greedy/cplex，实例无关、零训练）直接在 test 上评估；MARL 在 train 训练、val 调参、test（2 实例 × 30 seeds）终评，另报告 train 均值–test 均值之差（泛化代价，指标⑩）。

## 2. 生成命令与参数

```bash
python experiments/gen_dn_data.py --seeds 1,2,...,30 --m 5 --n 100 --K 10 \
    --mu 6 --w-trend 1.5 --quota 2,2,6 --outdir data/dn-data-v4 --pad 2
```

| 参数 | 值 | 与 v3 的关系 |
|---|---|---|
| m / n / K | **5 / 100 / 10**（每波恰 10 个到达） | m 3→5（Agent ×1.67）、n 50→100（×2）；K 不变 |
| dt / delta_d / v_m / pcap | 10 s / 3.0 km/步 / 1.0 km/s / 95 | 不变 |
| **mu** | **6 / 平台（全局共享池 30 发）** | 数值不变；**池/发射需求 = 30/45 = 0.67 = v3 的 18/27（压力结构精确平移）**；满配发射第 6 个决策步（t=5）耗尽池，与 v3 相同 |
| **w-trend** | **1.5**：`w = max(1, round(U{1..99} × (1 + 1.5·k_arr/(K−1))))`，取值 [1, 248] | 公式不变；30 实例合并实测窗 0 → 窗 9：51.1 → 120.8（比值 2.365，单调非降） |
| **quota** | **2,2,6**（每波 1/2/3 步交战窗 = 2/2/6 个） | v3 (1,1,3) 等比 ×2；3 步窗仍占 60%，补射回路结构不变 |
| r0-min / r0-max / b-max / eps-max | 3 / 9 / 3 / 2 | 不变 |
| seed 流 | 每实例 5 条独立 `RandomState(seed*100+1..5)`（split/r0/b/eps/w-p，与 v3 一致） | 不变 |
| 实例 seed | = 文件号（s01→1 … s30→30） | 不变 |

回归校验（V7'）：修改后的生成器以 v3 缺省参数（`--seeds 1 --pad 2`）生成的实例与 `data/dn-data-v3/dn_3x50_K10_s01.txt` **逐字节一致**——v4 = v3 生成逻辑 + 规模参数差异，无隐藏改动。

## 4. 评估协议（与 v3 完全一致，仅数据目录不同）

- **所有算法在 v4 上的对比只在 test 的 2 个实例（s01/s02）上进行**（cplex 逐步求解 × 多 seeds 开销随 m×n 增长，2 实例即可支撑 mean±std 与同 seed 配对检验）；
- 蒙特卡洛种子数：**30**（seeds 42–71，与 v3 终评同区间）；
- 基线：`none` / `greedy` / `cplex`（/ `pocplex`），实例无关、零训练，直接在 test 上评；
- MARL：train（24 实例）训练、val（4 实例）调参、test（2 实例 × 30 seeds）终评；报告 train 均值–test 均值之差（泛化代价，指标⑩）；
- 批量评估入口：`experiments/dn_family_eval.py --data-dir data/dn-data-v4 --manifest data/dn-data-v4/MANIFEST.md --split <split> --policy <policy>`；
- **资源不变量（v2.0 环境修复后必查）**：任何策略任何 run 的 `shots_total ≤ m×mu = 30`、`ammo_end ≥ 0`、`pool_end ≥ 0`。
