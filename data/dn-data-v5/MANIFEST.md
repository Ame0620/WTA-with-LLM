# MANIFEST — DN-WTA v5 数据集（资源扩展族，固定划分协议）

> 生成日期：2026-09-18 ｜ 生成器：`experiments/gen_dn_data.py`（md5 `1bda6548a7712327aa9b24c54f5af14f`，与 v4 版逐字节相同——v5 生成**零代码修改**，仅 CLI 参数不同）
> 文件格式：DN-WTA v1（8 字段 Header + 三块，1+n+2mn = **2101** 行）；动力学/信息边界/指标口径与 v3/v4 完全一致，见 `DN-WTA_v5_数据集说明.md`。
> 定位：**资源扩展基准（m=10、mu=7、全局池 70）**：Agent 数 ×2、弹药 ×2.33，池/发射需求 = 70/90 ≈ 0.78（v4 为 0.67），满配 t=6 耗尽、理论拦截上限 70%；目标流与 v4 同 seed 逐值一致（跨版本继承性，见说明 §10）——跨 v4/v5 对比差异可精确归因于资源扩展。v3 仍为正式主基准，v4 为规模对照。

## 1. 固定划分（与 v3/v4 协议完全平移，禁止混用）

| split | 实例 | 用途 |
|---|---|---|
| **test** | s01–s02（2 个） | **v5 资源对比基准**：算法在 v5 上的对比统一只用这 2 个实例（× 30 MC seeds） |
| train | s03–s26（24 个） | MARL 训练 |
| val | s27–s30（4 个） | 调参 / 早停 |

任何算法的超参**不得**依据 test 表现调整。基线（none/greedy/cplex，实例无关、零训练）直接在 test 上评估；MARL 在 train 训练、val 调参、test（2 实例 × 30 seeds）终评，另报告 train 均值–test 均值之差（泛化代价，指标⑩）。

## 2. 生成命令与参数

```bash
python experiments/gen_dn_data.py --seeds 1,2,...,30 --m 10 --n 100 --K 10 \
    --mu 7 --w-trend 1.5 --quota 2,2,6 --outdir data/dn-data-v5 --pad 2
```

| 参数 | 值 | 与 v4 的关系 |
|---|---|---|
| **m** | **10**（Agent ×2） | m 5→10；联合动作维度 3m = 30 |
| n / K | 100 / 10（每波恰 10 个到达） | 不变 |
| dt / delta_d / v_m / pcap | 10 s / 3.0 km/步 / 1.0 km/s / 95 | 不变 |
| **mu** | **7 / 平台（全局共享池 70 发）** | 池 30→70（×2.33）；**池/发射需求 = 70/90 ≈ 0.78**（v4: 30/45 = 0.67）；满配发射第 7 个决策步（t=6）耗尽池 |
| w-trend | 1.5（公式不变，取值 [1, 248]） | 同 seed 下 w 序列与 v4 逐值一致 → total_value 逐实例相同（下表与 v4 MANIFEST 完全一致） |
| quota | 2,2,6 | 不变；3 步窗占 60% |
| r0-min / r0-max / b-max / eps-max | 3 / 9 / 3 / 2 | 不变 |
| seed 流 | 每实例 5 条独立 `RandomState(seed*100+1..5)`（split/r0/b/eps/w-p） | 不变；同 seed 下目标块 + 前 5 平台 p/d0 与 v4 逐值一致 |
| 实例 seed | = 文件号（s01→1 … s30→30） | 不变 |
